# Dashboards

What the household sees at a glance. Displays use the other contexts' language and never redefine it.

## Language

**Display**:
A dashboard the household looks at, such as Our Home or the Wallboard. Nothing depends on a Display, so it can be removed without anything else noticing.
_Avoid_: Screen, UI, panel

**Our Home**:
The household's main Display, opened on phones and computers, with a view per theme of the home.
_Avoid_: Overview, main dashboard, home dashboard

**Wallboard**:
A Display that runs as an appliance on a wall-mounted screen, always on, showing the day and anything needing attention.
_Avoid_: Kiosk, tablet, family board
